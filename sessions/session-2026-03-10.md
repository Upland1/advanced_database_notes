# Session – 2026 - 03 - 10

## Topics covered
This session focused on SQL set operators, which allow combining the results of multiple queries into a single result set.  
These operators treat query results like mathematical sets and enable operations such as union, intersection, and difference.
These are useful for comparing tables, merging datasets, and finding differences between tables.

- Set operators
- UNION
- UNION ALL
- DISTINCT
- MINUS (set difference)
- INTERSECT
- Symmetric difference
- Comparing tables
- Handling NULL values in set operations
- Using GROUP BY to compare datasets

---

## What I understood

### UNION
Combines the results of two queries and removes duplicate rows automatically.

Requirements:
- Same number of columns
- Compatible data types

Example:

```sql
SELECT colour FROM my_brick_collection
UNION
SELECT colour FROM your_brick_collection
ORDER BY colour;
```

Result:
- All colours from both tables
- Duplicates removed

---

### DISTINCT behavior
`UNION` automatically performs a `DISTINCT` operation.

Equivalent idea:

```sql
SELECT DISTINCT *
FROM (
  SELECT colour, shape FROM my_brick_collection
  UNION ALL
  SELECT colour, shape FROM your_brick_collection
);
```

---

### UNION ALL
Combines results but **keeps duplicates**.

Example:

```sql
SELECT shape FROM my_brick_collection
UNION ALL
SELECT shape FROM your_brick_collection
ORDER BY shape;
```

Key idea:
- Faster than UNION
- Shows every row from both tables

---

### MINUS (Set Difference)
Returns rows that exist in the first query but **not in the second**.

Example:

```sql
SELECT shape FROM my_brick_collection
MINUS
SELECT shape FROM your_brick_collection;
```

Key points:
- Removes duplicates
- Treats NULL values as equal
- Equivalent concept to **A − B**

---

### INTERSECT
Returns rows that appear in **both tables**.

Example:

```sql
SELECT colour FROM my_brick_collection
INTERSECT
SELECT colour FROM your_brick_collection
ORDER BY colour;
```

Key idea:
- Finds common values between datasets
- Also removes duplicates

---

### Finding symmetric differences
Symmetric difference means:
Values that appear **only in one table but not both**.

Method using `MINUS` and `UNION ALL`:

```sql
(
  SELECT colour, shape FROM your_brick_collection
  MINUS
  SELECT colour, shape FROM my_brick_collection
)
UNION ALL
(
  SELECT colour, shape FROM my_brick_collection
  MINUS
  SELECT colour, shape FROM your_brick_collection
);
```

This returns rows unique to each table.

---

### Comparing tables with GROUP BY
Another approach is combining rows using `UNION ALL` and counting occurrences.

Example idea:

```sql
SELECT colour, shape,
       SUM(your_bricks),
       SUM(my_bricks)
FROM (
  SELECT colour, shape, 1 your_bricks, 0 my_bricks
  FROM your_brick_collection
  UNION ALL
  SELECT colour, shape, 0 your_bricks, 1 my_bricks
  FROM my_brick_collection
)
GROUP BY colour, shape
HAVING SUM(your_bricks) <> SUM(my_bricks);
```

Benefits:
- Reads tables only once
- Shows which table has extra rows
- Shows how many extra rows exist
