### Goal
Create table in Oracle 23ai

### SQL

```sql
BEGIN
  EXECUTE IMMEDIATE 'DROP TABLE doc_chunks';

END;
/

CREATE TABLE doc_chunks (
    chunk_id     NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    doc_name     VARCHAR2(200),
    chunk_text   VARCHAR2(2000),
    chunk_vector VECTOR(384, FLOAT32)
);

SELECT table_name FROM user_tables WHERE table_name = 'DOC_CHUNKS';
```

### Key Concepts
- VECTOR(384) stores embeddings
- Each row = one text chunk

## Step 6 — Generate INSERT Statements

### Problem
- Oracle limit: 4000 characters
- Vector ≈ 4600 chars → causes error

### Solution
Split vector using `TO_CLOB()`

### Code

```python
def format_vector(embedding):
    values = ", ".join(f"{v:.8f}" for v in embedding)
    full = f"[{values}]"
    mid = len(full) // 2
    split_pos = full.rindex(',', 0, mid) + 1
    part1 = full[:split_pos]
    part2 = full[split_pos:]
    return f"TO_VECTOR(TO_CLOB('{part1}') || '{part2}', 384, FLOAT32)"
```

### Insert Example

```sql
INSERT INTO doc_chunks (doc_name, chunk_text, chunk_vector)
VALUES ('Vector database', 'text...', TO_VECTOR(...));

COMMIT;

SELECT COUNT(*) FROM doc_chunks;
```

### Code

```python
MY_QUESTION = "What is a vector database used for?"
TOP_N = 3

```

### SQL Query

```sql
SELECT
    chunk_id,
    SUBSTR(chunk_text, 1, 100) AS preview,
    ROUND(VECTOR_DISTANCE(chunk_vector, <query_vector>, COSINE), 4) AS similarity_score
FROM doc_chunks
ORDER BY similarity_score ASC
FETCH FIRST 3 ROWS ONLY;
```

### Key Insight
- Lower score → more similar
- Uses **cosine similarity**
