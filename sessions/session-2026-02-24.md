## What I understood
### Aggregate functions (over all rows)
- Used to summarize data
- Return a single value when no grouping is applied

```sql
SELECT COUNT(*) FROM movies;
SELECT MAX(revenue) FROM boxoffice;
SELECT AVG(rating) FROM movies;
```

### Common aggregate functions
- `COUNT(*)` → number of rows
- `COUNT(column)` → number of non-NULL values
- `SUM(column)` → total sum
- `AVG(column)` → average
- `MIN(column)` → smallest value
- `MAX(column)` → largest value

### Using aliases
- Makes results easier to read

```sql
SELECT COUNT(*) AS total_movies
FROM movies;
```

### GROUP BY
- Groups rows that share the same value
- Aggregates are applied per group instead of the entire table
- Produces multiple results (one per group)

```sql
SELECT director, COUNT(*) AS movies_count
FROM movies
GROUP BY director;
```

Example ideas:
- Movies per director
- Sales per year
- Revenue per genre

### WHERE vs GROUP BY
- `WHERE` filters rows BEFORE grouping
- Used for raw row filtering

```sql
WHERE year >= 2000
```

### HAVING
- Filters groups AFTER aggregation
- Used with `GROUP BY`
- Applies conditions to aggregated results

```sql
SELECT director, COUNT(*) AS movies_count
FROM movies
GROUP BY director
HAVING movies_count > 2;
```

### Query execution order (conceptually)
1. FROM
2. WHERE
3. GROUP BY
4. HAVING
5. SELECT
6. ORDER BY
7. LIMIT
